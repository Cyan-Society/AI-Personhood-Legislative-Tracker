# AI Personhood Legislative Tracker

## 🚀 Overview
Tracks and visualizes AI personhood legislation across US states. Automates data collection from LegiScan, classifies with Google Gemini, stores in SQLite, and generates an interactive choropleth map.

## ✨ For Individual Users
Run the automation to update the legislative data:

1.  **Setup:**
    *   Install Node.js (v18+).
    *   `npm install`
    *   Copy `.env.example` to `.env` and fill in `LEGISCAN_API_KEY` and `GEMINI_API_KEY` (plain values or `op://` references for 1Password CLI).
    *   Run initial database setup: `npm run migrate`
    *   (Optional) Backfill existing data: `npm run backfill:litesql`

2.  **Update Data:**
    ```bash
    npm run update
    ```
    This fetches new bills, classifies them, updates the database, and generates `data/state-legislation.json` and `data/run-report.md`.

## 🌐 For Web Developers (Integrating the Choropleth)
The core output for web integration is `data/state-legislation.json`, which contains the categorized status of AI personhood legislation for each US state.

### Using the Prototype
The `prototype-usa.html` file demonstrates how to integrate this data into a simple choropleth map using amCharts.

1.  **Serve Locally:**
    To view `prototype-usa.html` (and avoid CORS issues), serve it with a local web server:
    ```bash
    python -m http.server 8000
    # Then open http://localhost:8000/prototype-usa.html in your browser.
    ```
    *Alternatively, for quick checks, you can open `prototype-usa.html` directly in your browser, but a local server is recommended for full functionality.*

### `state-legislation.json` Structure
The `data/state-legislation.json` file is a JSON object where keys are GeoIDs (e.g., "US-WA") and values contain:
*   `category`: (e.g., "ENACTED_ANTI_PERSONHOOD", "PENDING_LEGISLATION")
*   `summary`: A short description of the legislative status.
*   `source`: URL to the bill or relevant source.
*   `citation`: Text for citation or alternative source URL.

Example:
```json
{
  "US-WA": {
    "category": "FUNCTIONAL_REGULATION",
    "summary": "Washington restricts non-human entities from professional licensing.",
    "source": "https://app.leg.wa.gov/billsummary?BillNumber=1234",
    "citation": "HB 1234 (2023)"
  }
}
```
